# InboxSort -- Screenshot Guide for Chrome Web Store

Chrome Web Store allows up to 5 screenshots (1280x800 or 640x400 recommended).
Below is the recommended set, in order, with instructions for what to capture and what caption/overlay text to add.

---

## Screenshot 1: The Sort Toolbar in Action
**What to show:**
A full Gmail inbox view with the InboxSort toolbar visible below Gmail's action bar. The "Date" sort tab should be active (highlighted), showing emails sorted oldest-first. The stats bar should be visible with realistic counts (e.g., "42 emails - 7 unread - 3 starred - 5 attachments"). Use a populated inbox with a mix of read/unread emails from recognizable-looking sender names.

**Caption overlay text:**
"Sort your Gmail inbox by date, sender, or unread status -- right inside Gmail."

**Design notes:**
- Keep the overlay text at the top or bottom, semi-transparent background strip
- Use the extension's blue accent color for any highlight accents
- This is the hero screenshot -- it should immediately communicate what the extension does

---

## Screenshot 2: Group by Sender
**What to show:**
The same inbox with "Group by Sender" enabled. Sender group badges should be visible (colored labels like "Google (3)", "Amazon (2)") overlaid on the email rows. The Group tab in the toolbar should be active. This is one of the most visually distinctive features.

**Caption overlay text:**
"Group emails by sender with color-coded badges and counts."

**Design notes:**
- Make sure several different sender groups are visible with different badge colors
- This screenshot should feel visually rich and organized

---

## Screenshot 3: Filters and Search
**What to show:**
The inbox with the "Unread" quick filter active (the unread stat in the stats bar should appear highlighted/active). Some email rows should be dimmed (filtered out) while unread emails remain fully visible. The search input should have some text typed in it (e.g., "invoice") with a match count visible. The "Select visible" bulk-select button should be visible in the stats bar.

**Caption overlay text:**
"Filter by starred, unread, or attachments. Search by sender, subject, or snippet."

**Design notes:**
- The contrast between dimmed (filtered-out) and visible rows is the key visual here
- Show the search bar with active text to demonstrate the live search feature

---

## Screenshot 4: Popup Settings Panel
**What to show:**
The InboxSort popup panel open (click the extension icon). Show the full popup with:
- Sort Order section with one option selected
- Quick Filters chips
- Accent Color picker with one color selected
- Settings toggles (auto-sort on load, remember per label)
- Pause Sorting buttons

**Caption overlay text:**
"Customize everything: auto-sort, per-label preferences, accent colors, and more."

**Design notes:**
- Capture the popup at full size against the Gmail background
- The popup should look polished and well-organized
- Consider showing the teal or purple accent to demonstrate color customization

---

## Screenshot 5: Keyboard Shortcuts Cheat Sheet
**What to show:**
The keyboard shortcut cheat sheet overlay (press ? to open it). The overlay should be centered on screen showing all available shortcuts organized by section (Sort Modes, Filters & Search, Other). The Gmail inbox should be dimly visible behind the semi-transparent backdrop.

**Caption overlay text:**
"Full keyboard shortcuts for power users. Press ? to see them all."

**Design notes:**
- The cheat sheet overlay is visually impressive and signals "power user tool"
- Make sure the text in the overlay is readable
- The backdrop blur/dim effect adds polish

---

## General Guidelines

**Resolution:** Capture at 1280x800 pixels (the recommended Chrome Web Store size).

**Consistency:** Use the same Gmail account/inbox data across all screenshots so the experience feels cohesive.

**Theme:** Capture all screenshots in Gmail's light mode for maximum clarity and contrast. Consider adding one bonus dark-mode screenshot if permitted.

**Overlays:** Keep caption text clean and legible. Use a semi-transparent dark bar (rgba(0,0,0,0.7)) at the top or bottom with white text, 18-20px font, no more than one sentence per screenshot.

**Branding:** Include the InboxSort name subtly in the first screenshot overlay (e.g., "InboxSort" logo or wordmark in the corner).

**Order rationale:**
1. Hero shot -- immediately shows what the extension does
2. Group by Sender -- the most visually distinctive feature
3. Filters/Search -- demonstrates depth of functionality
4. Settings -- shows customization and polish
5. Keyboard shortcuts -- appeals to power users and signals quality
