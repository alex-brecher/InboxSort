InboxSort: Sort Gmail your way

Sort Gmail by date, sender, starred status, or unread status. InboxSort adds a compact toolbar and a clear settings popup to Gmail.

FEATURES:

Sort Modes (6 options):
• Oldest First: See your oldest emails at the top
• Newest First: Restore Gmail's default order with one click
• Sender A to Z: Sort by sender name in alphabetical order
• Sender Z to A: Sort by sender name in reverse alphabetical order
• Unread First: Put unread messages first
• Starred First: Put starred messages first, then sort each group by newest date

Group by Sender:
• Cluster messages from the same sender
• Use grouping with each sort mode

Quick Filters:
• Starred: Show only starred emails
• Unread: Show only unread messages
• Attachments: Show only emails with attachments
• Combine multiple filters at once

Inline Search:
• Filter visible emails by sender, subject, or snippet
• Real-time match count as you type
• One-click clear

Stats Bar:
• Live count of total, unread, starred, and attachment emails
• Click any stat to toggle it as a filter

Keyboard Shortcuts:
• Alt+1 through Alt+5 for the original sort modes
• Alt+6 to group messages by sender
• Alt+7 to sort starred messages first
• Alt+0 to reset to default

Settings:
• Auto-sort on page load
• Remember sort preference per label
• Snooze sorting temporarily (15m, 30m, 1h)
• 6 accent colors to match your style
• Choose which toolbar controls appear
• Export and import your settings
• Sort and group changes stay in sync across open Gmail tabs
• Chrome sync stores your preferences across signed-in browsers

WHY INBOXSORT?

• Uses a toolbar that matches Gmail
• Uses CSS transforms for fast visual sorting
• Keeps your data in your browser and does not use tracking
• Works in Inbox, categories, search results, and custom labels
• Dark mode support
• Fast and responsive
• Keyboard-accessible controls and reduced-motion support

OPEN SOURCE:
• Review the source code or report an issue at https://github.com/alex-brecher/InboxSort

PERMISSIONS:
• activeTab: Runs InboxSort in the active Gmail tab
• storage: Saves and syncs your InboxSort preferences

InboxSort does not collect or transmit personal data. InboxSort processes the visible message list in your browser.
